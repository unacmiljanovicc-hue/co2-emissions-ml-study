# Data

`raw/GCB2022v27_MtCO2_flat.csv` is the country-level Global Carbon Budget emissions file used in the original project.

The notebook also downloads selected socioeconomic and energy variables at runtime from the public Our World in Data CO₂ dataset:
`https://raw.githubusercontent.com/owid/co2-data/master/owid-co2-data.csv`

If redistributing this repository publicly, review the original datasets' current licenses and attribution requirements.
